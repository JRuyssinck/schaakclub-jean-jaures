# Schaakclub Jean Jaurès Website — Design

**Date:** 2026-08-10
**Status:** Approved

## Purpose

A public website for Schaakclub Jean Jaurès (Gent, Flanders), hosted on GitHub Pages, to:

- Serve as an info & contact hub (schedule, location, how to join).
- Publish news/events (tournaments, club activities) and results/standings.
- Help recruit new members.

## Background research

Sourced from Dutch Wikipedia, the Belgian Chess Federation (FRBE-KBSB) club registry, and web search (facts to be verified by the club before publishing):

- Founded in **1945** at the Jean Jaurès community center on Ryhovelaan, Gent — named after French socialist Jean Jaurès.
- By 1947 the club had 100+ members, boosted by a weekly chess column by Prudent Quintijn in the socialist newspaper *Vooruit*.
- **National champion in 1971 and 1973** (top division of the Belgian interclub competition).
- Currently competes in the **Oost-Vlaanderen league (VSF)**, club #402.
- Meets Tuesday evenings (adults, main location) and Friday evenings + weekend youth lessons (Sat 13:00, Sun 9:30) at a location in Ledeberg.
- Publishes a club newsletter called **"Rochade."**
- Sources disagreed on the current adult meeting address (GITO Martelaarslaan 13 vs. Reigerstraat 8) and no confirmed current contact email/fees were found reliably — **these fields are placeholders in the built site and must be confirmed by the club before going live.**

## Scope

### Pages

- **Home** — welcome, highlights, tagline, founding year.
- **About / History** — the 1945 founding story, 1971/1973 titles, club identity.
- **Schedule & Location** — meeting days/times, address(es), map embed. Contains placeholder fields pending club confirmation.
- **News / Events** — list of news items (tournaments, club evenings, announcements).
- **Join / Contact** — how to become a member, fees (placeholder), contact email/form.
- **Gallery** — photos from club evenings/tournaments.
- **Results / Standings** — manually entered interclub results per season/round.

All pages exist in **Dutch (default) and English (toggle)**. Dutch is canonical; `/` redirects to `/nl/`.

### Out of scope (for this iteration)

- Live integration with KBSB/VSF results feeds (manual entry only, for now).
- CMS or non-technical editing workflow (maintainer is comfortable editing Markdown/code directly).
- French translation.
- Visual/branding polish — ships with a reasonable default theme (see below); refinable later purely via CSS, independent of content/structure.

## Architecture

Static site generated by **Jekyll**, built natively by GitHub Pages (no CI/build pipeline to maintain).

```
/
├── _config.yml              # site config, nav, defaults
├── _layouts/                 # default.html, page.html, news-item.html, gallery-item.html
├── _includes/                 # header, footer, language-switcher, nav
├── _news/                     # collection: one .md file per news item (nl/en pairs)
├── _results/                   # collection: one .md file per season/round result
├── gallery/                    # images + a gallery.md page rendering them
├── nl/                          # index, about, schedule, join (Dutch, canonical)
├── en/                           # index, about, schedule, join (English)
├── assets/
│   ├── css/                       # styles
│   └── img/                        # logo, photos, board/piece motifs
├── 404.html                        # bilingual custom 404
└── README.md                        # how to add a news item / photo / result
```

### Content model

- **News item**: front matter `title`, `date`, `lang`, `lang_ref` (slug of the translated pair), `excerpt`; Markdown body. Listed on `/news/`, newest first, plus its own page.
- **Gallery**: single `gallery.md` page listing photo albums (front-matter list of `images`), simplest option given expected volume. Can split into one file per event later if needed.
- **Result**: `_results/<season>-<round>.md` with front matter (`season`, `division`, `round`, `opponent`, `score`). Rendered as a table on `/results/`. Manual entry only.
- **Static pages**: plain Markdown, one per language, sharing layouts/includes.

### i18n approach

No i18n plugin (GitHub Pages' Jekyll plugin whitelist is limited). Manual parallel structure instead:
- `/nl/...` and `/en/...` directories mirror each other page-for-page.
- Each page's front matter includes a `lang_ref` pointing to its translated counterpart.
- A shared `_includes/lang-switcher.html` renders a link to the counterpart using `lang_ref`.
- News/result collection items are filtered by a `lang` front-matter field within otherwise-shared collections.

## Visual design

Wooden/chess theme, refinable later without touching structure or content:

- **Palette:** walnut brown (headers/text), cream/ivory (background, board-square white), muted sage/olive (accent), warm gold/brass (links/highlights) — softer than a stark black/white chessboard.
- **Typography:** serif for headings (classic club feel), clean sans-serif for body copy.
- **Motifs:** subtle low-opacity chessboard-square texture as a section divider; a small knight/pawn silhouette as a recurring icon, not a busy repeating pattern.
- **Layout:** top nav (Home / About / Schedule / News / Gallery / Results / Join) + language switcher; warm hero on the homepage (club name, founding year, tagline); card-style news list; simple photo grid for gallery; table for results.

## Error handling & testing

- Custom bilingual `404.html` for broken links.
- No automated tests — static content site. Validation is: Jekyll build succeeds, both language trees render, internal links resolve. Manual review pass before considering it done.

## Deployment

- GitHub repository, GitHub Pages enabled on the default branch (root), Jekyll built natively by Pages — no GitHub Actions workflow required.
- `README.md` documents: how to add a news item, a gallery entry, a result, and how to preview locally (`bundle exec jekyll serve`) — optional, since GitHub also builds automatically on push.
